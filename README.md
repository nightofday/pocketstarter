# PocketStarter

A boilerplate built with Next.js and PocketBase.

## Documentation

📚 For detailed documentation and guides, visit [pocketstarter.dev/docs](https://pocketstarter.dev/docs)

## Tech Stack

- **Frontend**: Next.js with TypeScript
- **Backend**: PocketBase
- **Package Manager**: pnpm

## Project Structure

```
├── frontend/        # Next.js frontend application
└── pocketbase/      # PocketBase backend
```

## Getting Started

### Prerequisites

- Node.js (Latest LTS version recommended)
- pnpm
- PocketBase

### Frontend Setup

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   pnpm install
   ```

3. Start the development server:
   ```bash
   pnpm dev
   ```

### Backend Setup

1. Download PocketBase from the [official releases page](https://github.com/pocketbase/pocketbase/releases/latest)

2. Extract the downloaded archive to the `pocketbase` directory

3. Start PocketBase server:
   ```bash
   cd pocketbase
   ./pocketbase serve
   ```
